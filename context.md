# Project Two: Context & Workspace Overview

## 1. Overview
This branch (`project-two`) is dedicated to developing the second project within the `mi-project-one` repository. By utilizing orphan git branches and segregated project folders, multiple applications can be maintained in the same GitHub repository without code collisions or bloated bundle sizes.

---

## 2. Repository Organization

- **Active Branch:** `project-two`
- **Primary Main Branch:** `main` (hosts Operation Dead Drop: Full-stack Rust Axum + React TypeScript zero-knowledge war room)
- **Directory Root:** `projects/project-two/`

---

## 3. Workflow & Branch Switching

```bash
# Verify current branch
git branch --show-current

# Switch between projects cleanly
git checkout main         # Access Operation Dead Drop
git checkout project-two  # Access Project Two
```
